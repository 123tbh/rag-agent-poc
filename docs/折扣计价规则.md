# 电商平台折扣计价规则（示例）

平台支持 8 种折扣类型：①区域培训班固定价 ②区域折扣 ③区域科目类型折扣 ④区域培训班折扣 ⑤单位折扣 ⑥单位培训班折扣 ⑦个人折扣 ⑧个人培训班折扣。

计价顺序：先看⑧个人培训班折扣——整班购买且年份符合时只按⑧计算（原价×折扣率），其他折扣不参与；⑧不生效时按①→②→③→④→⑤→⑥的固定顺序找第一条可用的基础折扣，找到即停。最后叠加⑦个人折扣：最终价格 = 上一步结果 × 个人折扣率。

金额保留两位小数，每个班级只在最后四舍五入一次。折扣与优惠券互斥：订单中任一班级命中折扣则整单不可用券。规则只对新订单生效，不改变已有订单金额，不影响退款和分成。
